# Эксперимент: Сравнение ответов LLM-Чата и AI-Агента

## О проекте
Этот проект создан для наглядной демонстрации разницы между обычным LLM-чатом и AI-агентом, способным использовать внешние инструменты (function calling).

## Технологии
- Node.js (без внешних фреймворков)
- OpenRouter API
- HTML/CSS для интерфейса

## Структура проекта
├── **proxy-agent.js** # Сервер AI-агента (с инструментами)

├── **proxy-chat.js** # Сервер обычного чата (без инструментов)

├── **index.html** # Веб-интерфейс (общий для обоих)

├── **package.json** # Зависимости

└── **.env** # Файл с API-ключом (создаётся локально)

## Как запустить

1. **Клонируйте репозиторий:**
   ```
   git clone <ссылка на ваш репозиторий>
   cd <папка-проекта>
   ```
2. **Установите зависимости:**
    ```
    npm install
    ```
3. **Настройте API-ключ:**
    - Создайте в корневой папке файл .env
    - Добавьте в него свой ключ от OpenRouter: 
    ```
    OPENROUTER_API_KEY=sk-or-v1-ваш_ключ
    ```
4. **Запустите один из серверов**

    _Для AI-агента (с инструментами):_
    ```
    node proxy-agent.js
    ```
    _Для обычного LLM-чата (без инструментов):_
    ```
    node proxy-chat.js
5. **Откройте в браузере:** 
    ```
    http://localhost:3000
    ```
## Что проверяет этот проект:
Проект позволяет сравнить ответы на три типа вопросов:

**О времени:** Агент получает реальное время через инструмент get_current_time

**О вычислениях:** Агент точно считает через инструмент calculate

**О длине текста:** Агент точно подсчитывает символы через text_length

# Вопрос 1 Проверка времени #

**Запрос:** `"Сколько сейчас времени в Париже?"`

**Ответ:**

**Обычный LLM-чат** - _`В Париже действует центральноевропейский часовой пояс (CET)`_

**AI-Агент** - _`Сейчас в Париже 16:40 (по местному времени)`_

# Вопрос 2: Проверка вычислений #

**Запрос:** `"Сколько будет 99999999 умножить на 88888888?"`

**Ответ:**

**Обычный LLM-чат** - _`\(99999999 \times 88888888\) Запишем один из множителей как разность \[ 99999999 = 10^{8}-1 . \] Тогда \[ 99999999 \times 88888888 =(10^{8}-1)\cdot 88888888 =10^{8}\cdot 88888888 - 88888888 .` _

**AI-Агент** - _`Результат умножения: 8888888711111112`_

# Вопрос 3: Проверка длины текста #

**Запрос:** `"Сколько символов в слове Тысячадевятьсотвосьмидесятидевятимиллиметровый?"`

**Ответ:**

**Обычный LLM-чат** - _`44`_

**AI-Агент** - _`46 символов`_

## Вывод

AI-агент с функцией вызова инструментов (function calling) точно отвечает на вопросы, требующие:

* реального времени

* математических вычислений

* точного подсчёта символов

Обычный LLM-чат в этих сценариях ошибается или не может ответить.
